# System Newsletter // Interactive Stories

Edición interactiva con scrollytelling visual, parallax cinematográfico en tiempo real y diseño editorial de alta fidelidad.

## 📱 Proyecto Activo: 01 - YAPE: La Historia
> *"El imperio que casi muere en 72 horas"*

Explora la historia interactiva del lanzamiento de Yape con una experiencia inmersiva que combina:
- **Hero Stage con Parallax Multinivel**: Capas de cielo, nubes, edificios de fondo y frente con movimiento continuo y respuesta fluida al cursor del mouse.
- **Micro-animaciones fluidas**: Respiración orgánica de Yape en su eje y cinemática en tiempo real.
- **Editor Visual Integrado**: Herramienta de calibración en vivo para ajustar escala, posición y parámetros de las capas.
- **Soporte Full Responsive**: Adaptación precisa tanto para Desktop (1440p/1080p) como para Mobile (iPhone / Android).

---

## 🚀 Inicio Rápido

### Requisitos
- Node.js 18+
- npm o pnpm

### Ejecución Local
```bash
# Entrar a la app interactiva
cd 01-YAPE_La_Historia/app

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

### Compilar para Producción
```bash
npm run build
```
